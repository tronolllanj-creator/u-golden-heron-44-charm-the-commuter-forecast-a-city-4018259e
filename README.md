# Charm the Commuter: Forecast a City That Isn't

Mistcliff: fog so thick the lighthouse keeps bumping into the cliffs — foghorns on concussion protocol.

Its surreal fog‑laden scene turns a mundane ride into a miniature adventure.

Run with `python3 main.py`; it writes the forecast to `entry.txt`.
